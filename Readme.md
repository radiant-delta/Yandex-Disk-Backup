Скрипт для загрузки зашифрованного архива на Яндекс.Диск  
Поскольку аудитория Яндекс.Диска на 99% русскоязычная, readme.md на русском.  
Я использую в первую очередь для резервного копирования хранилища obsidian, но можно закидывать на Яндекс.Диск любую папку.  
Тестировалось на Windows 10.  
Используется REST API.

#### Структура алгоритма
1. Проверка активного VPN перед выполнением.  
Используется примитивный алгоритм, работающий только для приложения Amnezia
2. Создание зашифрованного архива в рабочей директории
3. Загрузка в папку приложения на Яндекс.Диске
4. Зачистка хвостов: удаление локального архива и старых бэкапов в облаке

Поскольку срок жизни токена довольно долгий (чуть меньше года), автоматическое обновление токена в скрипте (пока) не предусмотрено.
 
#### Как использовать
1. Идём на https://oauth.yandex.ru/client/new/
2. Регистрируем приложение
Запрашиваемые права:
- Доступ к папке приложения на Диске
- Доступ к информации о Диске
В поле Redirect URI введите значение `https://oauth.yandex.ru/verification_code`
3. Копируете Client_ID
4. Перейдите по ссылке вида: `https://oauth.yandex.ru/authorize?response_type=token&client_id=<Client_ID>`
и скопируйте токен
5. Занесите токен в скрипт, укажите целевую папку на компьютере.
6. Рекомендуется занести пароль архива в системные переменные через
```powershell
setx backup_password "ваш_надёжный_пароль"
```
или просто замените `запасной пароль` на ваш пароль  
7. Протестируйте работоспособность  
8. Установите резервное копирование по удобному расписанию в планировщик задач
